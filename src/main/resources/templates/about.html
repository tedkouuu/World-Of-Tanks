About World of Tanks

World of Tanks is an interactive armored vehicle archive and battle simulator.

Built With

Java 17
Spring Boot
MySQL
Thymeleaf
Spring Security
AWS S3

Key Features

  • Full CRUD operations for armored vehicles
  • Real-time battle simulation between tanks
  • Role-based access control (Admin / User)
  • Multi-language support (English / Bulgarian)
  • Advanced search and filtering
  • Responsive design for all devices
